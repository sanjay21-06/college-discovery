# College Discovery Platform

## Description

College Discovery is a full-stack web application that helps students explore and compare Indian colleges easily. Users can browse colleges, check fees, placements, ratings, reviews, compare multiple colleges, and save their favorite colleges after login.

---

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Supabase
* PostgreSQL
* Vercel

---

## Live Demo

```bash
https://college-discovery-six.vercel.app
```

## Features

* Browse Indian colleges
* College detail pages
* Compare multiple colleges
* Save favorite colleges
* Email authentication
* Google OAuth login
* Responsive UI design
* Reviews and ratings system
* Placement and fee information
